Cài đặt SASS Toàn Cục Bước 1

Cài đặt package Sass phiên bản Dart Sass thông qua npm ở phạm vi global để dùng ở bất kỳ thư mục nào.

npm install -g sass
Kiểm tra phiên bản SASS Bước 2

Kiểm tra xem SASS CLI đã được nhận diện trong hệ thống PATH và hiển thị phiên bản hiện hành.

sass --version
Biên dịch 1 tệp SCSS đơn lẻ Bước 3

Chuyển đổi trực tiếp từ file styles.scss thành file styles.css sẵn sàng nhúng vào HTML.

sass styles.scss styles.css
Chế độ Watch (Tự động biên dịch) Bước 4

Tự động lắng nghe thay đổi trong file SCSS và cập nhật CSS ngay lập tức khi bạn nhấn Save (Ctrl+S).

sass styles.scss styles.css --watch
Biên dịch cả thư mục SCSS Bước 5

Lắng nghe và chuyển đổi toàn bộ cấu trúc dự án từ thư mục scss/ sang thư mục css/.

sass scss/:css/ --watch
Sửa lỗi ExecutionPolicy PowerShell Gỡ lỗi

Nếu gặp lỗi bị chặn script trên Windows PowerShell, mở PowerShell bằng Administrator và chạy:

Set-ExecutionPolicy Unrestricted -Scope CurrentUser

🔄 Minh Họa Trực Quan: SCSS Nguồn vs CSS Kết Quả

Xem cách SASS giải quyết bài toán lồng nhau (nesting), biến (variables), và tính toán tự động

styles.scss (Mã nguồn SCSS) 
$primary-color: #ff3366;
$accent-color: #7928ca;
$text-light: #f8fafc;
$border-radius-base: 12px;

.single-demo-card {
  background: linear-gradient(135deg, 
    rgba($primary-color, 0.15), 
    rgba($accent-color, 0.15)
  );
  border: 1px solid rgba(255, 255, 255, 0.1);
  border-radius: $border-radius-base;
  padding: 24px;
  color: $text-light;
  transition: all 0.3s ease;

  &:hover {
    transform: translateY(-4px);
    box-shadow: 0 12px 24px rgba(0, 0, 0, 0.3);
    border-color: rgba($primary-color, 0.5);
  }

  .title {
    font-size: 1.5rem;
    font-weight: 700;
    color: $primary-color;
  }
}
styles.css (Biên dịch bằng SASS CLI) 
.single-demo-card {
  background: linear-gradient(135deg, rgba(255, 51, 102, 0.15), rgba(121, 40, 202, 0.15));
  border: 1px solid rgba(255, 255, 255, 0.1);
  border-radius: 12px;
  padding: 24px;
  color: #f8fafc;
  transition: all 0.3s ease;
}
.single-demo-card:hover {
  transform: translateY(-4px);
  box-shadow: 0 12px 24px rgba(0, 0, 0, 0.3);
  border-color: rgba(255, 51, 102, 0.5);
}
.single-demo-card .title {
  font-size: 1.5rem;
  font-weight: 700;
  color: #ff3366;
  margin-bottom: 8px;
}

Variables & Color Token

Quản lý tập trung mã màu, kích thước font, border-radius tại _variables.scss giúp việc đổi theme hoặc sửa đổi dễ dàng trong nháy mắt.

#variables

Mixins & Reusability

Tạo các hàm CSS tái sử dụng như @mixin flex-center, @mixin glass-panel, và @mixin responsive tiết kiệm hàng trăm dòng code lặp lại.

#mixins

Modern @use & Partials

Hướng dẫn đưa toàn bộ mã nguồn lên GitHub

# 1. Khởi tạo Git repository
git init

# 2. Thêm tất cả file vào staging
git add .

# 3. Tạo commit đầu tiên
git commit -m "feat: complete SASS installation with npm, SASS CLI and modular SCSS architecture"

# 4. Đổi nhánh chính sang main
git branch -M main

# 5. Thêm link repository GitHub của bạn (tạo repo mới trên github.com)
git remote add origin https://github.com/<your-username>/<your-repo-name>.git

# 6. Đẩy mã nguồn lên GitHub
git push -u origin main
