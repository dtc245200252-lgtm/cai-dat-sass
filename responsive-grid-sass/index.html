🎯 Báo Cáo Tái Cấu Trúc: CodeGym Responsive Grid

Resize cửa sổ trình duyệt để thấy hệ thống Grid phản hồi kích thước linh hoạt, luôn tận dụng 100% không gian hiển thị.

❌ Mã nguồn cũ (HTML/CSS hỗn tạp)

- Tràn ngập inline styles: style="height:90px;", style="width:25%;"
- Mã màu hex lặp lại nhiều lần
- Phụ thuộc vào thuộc tính float thủ công và tính toán cứng width: 8.33% 

<!-- Code cũ ngập tràn style inline -->
<div style="position:absolute;opacity:0.9;left:8px;">
  <div class="gridwrapper" style="height:90px;">
    <div class="gridcontent" 
         style="width:100%;background:#9933cc;"></div>
  </div>
  <div class="gridwrapper" style="height:230px;">
    <div class="gridcontent" 
         style="width:25%;padding-top:15px;">
      <div style="background:#33b5e5;height:15%;"></div>
    </div>
  </div>
</div>
✅ SASS Tái Cấu Trúc Chuẩn BEM & Modules

- Tách hoàn toàn CSS ra khỏi HTML, 0% inline style
- Sử dụng vòng lặp SASS @for $i from 1 through 12 sinh ra hệ thống cột tự động
- Quản lý tập trung màu sắc và chiều cao tại _variables.scss 

// Vòng lặp tự động sinh 12 cột trong SASS
@for $i from 1 through $grid-columns {
  .col-#{$i} {
    width: math.div($i, $grid-columns) * 100%;
  }
}

// BEM layout sạch sẽ
.layout-header {
  height: $height-header;
  &__content {
    width: 100%;
    background: $color-header;
  }
}
