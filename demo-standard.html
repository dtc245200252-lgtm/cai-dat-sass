So Sánh: CSS Trước Tối Ưu vs SASS Tối Ưu Bằng Mixin & Biến

❌ CSS Trước Khi Tối Ưu (Lặp giá trị, khó đổi theme)

h1 {
  font-size: 32px;
  color: #222;
}

h2 {
  font-size: 28px;
  color: #222;
}

.button {
  background: red;
  color: white;
  padding: 10px 20px;
  border-radius: 5px;
}

.card {
  background: white;
  padding: 15px;
  border-radius: 10px;
  box-shadow: 2px 2px 10px rgba(0, 0, 0, 0.1);
}

✅ SASS Sau Tối Ưu (Biến + Mixins + Tái sử dụng)

// 1. Khai báo biến (abstracts/_variables.scss)
$primary-color: red;
$text-color: #222;
$font-large: 32px;
$font-medium: 28px;
$padding-standard: 10px 20px;
$box-shadow-default: 2px 2px 10px rgba(0,0,0,0.1);

// 2. Định nghĩa mixins (abstracts/_mixins.scss)
@mixin button-style($bg-color) {
  background: $bg-color;
  color: white;
  padding: $padding-standard;
  border-radius: 5px;
}

@mixin box-style {
  background: white;
  padding: 15px;
  border-radius: 10px;
  box-shadow: $box-shadow-default;
}

// 3. Áp dụng vào Component & Base
h1 { font-size: $font-large; color: $text-color; }
h2 { font-size: $font-medium; color: $text-color; }
.button { @include button-style($primary-color); }
.card { @include box-style; }

Kết Quả Đạt Được

  • ✔ CSS trở nên gọn gàng, dễ quản lý hơn: Không còn lặp lại các giá trị kích thước, mã màu hay cấu hình bóng đổ rải rác trong dự án.
  • ✔ Kiểm soát giao diện tập trung: Khi thay đổi bảng màu (ví dụ từ đỏ sang xanh) hoặc kích thước typography, chỉ cần cập nhật tại một file _variables.scss duy nhất.
  • ✔ Tái sử dụng linh hoạt: Mixin button-style($bg-color) cho phép tạo nhanh các biến thể nút bấm mới chỉ bằng một dòng truyền tham số màu.
