Thành Quả Sau Khi Biên Dịch SASS sang CSS

Trang này đang sử dụng hoàn toàn file css/main.css, được biên dịch từ cấu trúc thư mục SASS module chuẩn: abstracts/, base/, layout/, và components/.

Đối chiếu kỹ thuật

So Sánh: CSS Ban Đầu vs SASS Chuẩn Hóa

❌ CSS Ban Đầu (Khó bảo trì, lặp code)

/* styles.css ban đầu */
body {
  font-family: Arial, sans-serif;
  color: #333;
  background: #f4f4f4;
}

.container {
  width: 80%;
  margin: 0 auto;
}

.button {
  background: blue;
  color: white;
  padding: 10px 20px;
  border-radius: 5px;
}

.card {
  border: 1px solid #ddd;
  padding: 20px;
  box-shadow: 2px 2px 10px rgba(0, 0, 0, 0.1);
}

✅ SASS Chuẩn Hóa (Tách Module, Biến, Mixin)

// scss/main.scss
@import "abstracts/variables";
@import "abstracts/mixins";
@import "base/global";
@import "layout/container";
@import "components/buttons";
@import "components/cards";

// components/_buttons.scss
.button {
  @include button-style($primary-color);
}

// components/_cards.scss
.card {
  border: 1px solid $border-color;
  padding: 20px;
  @include box-shadow;
}
Kiến trúc thư mục SASS

Cấu Trúc Thư Mục Chuẩn Đã Tạo

📁 scss/
├── 📁 abstracts/
│   ├── _variables.scss      # $primary-color, $text-color, $background-color, $border-color, $box-shadow
│   └── _mixins.scss         # @mixin button-style($bg-color), @mixin box-shadow
├── 📁 base/
│   └── _global.scss         # body { font-family, color, background }
├── 📁 layout/
│   └── _container.scss      # .container { width: 80%; margin: 0 auto; }
├── 📁 components/
│   ├── _buttons.scss        # .button { @include button-style($primary-color); }
│   └── _cards.scss          # .card { border, padding, @include box-shadow; }
└── main.scss                # Tập tin tổng hợp nạp tất cả partials
